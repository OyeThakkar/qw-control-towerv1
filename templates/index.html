Applied Cleanup Rules
1
Test Theatre Names: Marks bookings for Happy Cat, Happy Cow, and Happy Duck as TEST. Only exact case-insensitive matches are flagged; theatres like "Happy Cinemas" are not affected.
2
Qube Cinema Inc: Marks all bookings placed under the Qube Cinema Inc distributor account as TEST.
3
Dummy Delivery Notes: Marks entries with "Dummy booking for Test" or "Dummy booking for Download" in Distributor Delivery Notes as TEST.
4
Content Type Propagation: Within each Work Order, if any row is classified as Feature, all non-TEST rows in that order are set to Feature. Same logic applies for Trailer, Advert, Teaser, Short, and Promo.
5
CPL Name Refinement: Corrects misclassified Feature rows using CPL patterns — ADV→Advert, TLR/TRL→Trailer, SHR→Short, TSR→Teaser.
6
VF Content: Rows where CPL contains "VF" (not "OV"), Content Size < 30 GB, and Content Type is blank → set to VF.
+
Sales Region: A new Sales Region column is inserted immediately after Theatre Region, mapped from the Theatre Region value.
